# Minecraft Mod: Exiled Knight Ascension

Exiled Knight Ascension is a Fabric Minecraft RPG mod for version 1.21.1 that adds a fantasy class-progression system with a Divine Blessing class choice, skill-point tracking, guild contracts, and world lore about gods and dungeons. The project identifies itself in its mod metadata and commands as Magic World: Systembound Exile.

## Install

1. Install Minecraft 1.21.1, Java 21, Fabric Loader 0.16.9 or later, and Fabric API for Minecraft 1.21.1.
2. Build the project with `./gradlew build`.
3. Copy `build/libs/magic-world-1.0.0.jar` into your Minecraft instance’s `mods` folder.
4. Launch the Fabric profile.

## Use

1. Create or open a world with the mod installed.
2. Run `/mw help` for the command overview.
3. Run `/mw choose` to open the Divine Blessing class-selection screen, or use `/mw bless heavy_knight` to choose a class by command. A class choice is permanent.
4. Use `/mw skill iron_wall` or another available skill command to attempt to spend a skill point. The available nodes are Iron Wall, Shield Bash, Fortress Stance, Lucky Break, and Arcane Surge.
5. Use `/mw contract goblin_watch`, `/mw contract crypt_dive`, or another listed contract command to record a contract and receive a skill point.
6. Run `/mw status`, `/mw gods`, or `/mw regions` to view progression notes and setting information.
